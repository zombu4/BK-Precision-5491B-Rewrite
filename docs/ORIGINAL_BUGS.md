# ORIGINAL_BUGS.md -- defects found in the original 5491B firmware

A read-only static sweep of the original firmware image (ATmega128A). No hardware, serial port or programmer
was used. Addresses are byte addresses in the original image.

Rule: every pre-existing firmware bug is fixed in the replacement firmware. No bug is kept for
compatibility. Only the reply LAYOUT (field order, separators, "!" terminators) is preserved.

Status values: FIXED; REMOVED BY DESIGN (a command deliberately not implemented, with the rule that forbids
it); DECIDED (a recorded design decision); CLOSED (information only); UNVERIFIED (one claim, with the check
that settles it); HARDWARE (open until the named bench check is done); BLOCKED-ON-HARDWARE (cannot be
finished before a named board check). The status column holds the verdict
from reading the replacement source, with file:line.

`UNVERIFIED:` marks a claim the sweep could not prove, with the check that settles it.

## Summary

110 numbered rows. Each verdict was read from the replacement source (code reconcile 2026-10-23, rows #87, #94,
#101 and #102 updated 2026-10-24): 103 FIXED, 3 HARDWARE (#44, #103, #106), 1 BLOCKED-ON-HARDWARE (#101),
1 DECIDED (#60), 1 REMOVED BY DESIGN (#58), 1 CLOSED (#49).
