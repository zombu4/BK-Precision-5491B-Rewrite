# ORIGINAL_BUGS.md -- defects found in the original 5491B firmware

A read-only static sweep of the original firmware image (ATmega128A). No hardware, serial port or programmer
was used. Addresses are byte addresses in the original image.

Rule: every pre-existing firmware bug is fixed in the replacement firmware. No bug is kept for
compatibility. Only the reply LAYOUT (field order, separators, "!" terminators) is preserved.

Status values: OPEN, FIXED-BY-DESIGN (closed by a design decision), or BLOCKED-ON-HARDWARE with the exact
check needed. "(port changed; verify)" means the ported code already contains a change and the fix has to be
checked against the row. A status is as recorded when the row was written; the behaviour of the replacement
firmware is in its source and in PROTOCOL_CHANGES.md.

`UNVERIFIED:` marks a claim the sweep could not prove, with the check that settles it.

## Summary

110 numbered rows, one of which (#49) is information only. Status words as recorded: 82 OPEN, 14 FIXED,
5 FIXED-BY-DESIGN, 5 BLOCKED-ON-HARDWARE, 3 APPROVED, 1 CLOSED.
